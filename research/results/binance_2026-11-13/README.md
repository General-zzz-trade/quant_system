# 币安公开数据研究结果（2026-11-13）

**结论：BTCUSDT 和 ETHUSDT 都没有通过预先声明的上线门槛。主网执行保持拒绝。**
本次最终测试窗口（2025-11-16 至 2026-11-12）已经看过一次。之后的研究不得再用这一窗口挑选参数，下一轮最终测试必须使用 2026-11-13 之后的新数据。

## 设置

- **数据：** 币安 USDⓈ-M 公开数据。1h K 线、已结算资金费、5 分钟 OI 和多空比（OI/多空比约从 2021-12 开始），指纹见 `data_manifest.json`。
- **区间：** 2021-12-02 至 2026-11-12。按时间切分：
  - 训练：2021-12 至 2024-11-20；
  - 验证：2024-11-20 至 2025-11-16；
  - 最终测试：2025-11-16 至 2026-11-12。
- **决策与撮合：**
  - 决策层是生产 `AlphaDecisionModule`，研究和纸面运行时共用；
  - 撮合模型是 `runner/offline/broker.py`：挂单（post-only，参考价减 2bp，必须严格穿透才算成交），出场为市价且计 3bp 滑点；
  - 费用：maker 2bp、taker 5bp，计资金费，敞口上限 1 倍。
- **候选：** 每个币种 18 个，即 2 个特征集 × 3 个标签周期 × 3 个 deadzone。alpha 在每个特征集、周期组合内按验证集 IC 选出。
- **选择规则：** 验证集回放日夏普最高，且成交不少于 20 笔。选定后用训练加验证数据重训，冻结协议，然后才跑最终测试。

门槛未通过的原因：
- **BTC：** 日夏普不大于 1；成本翻倍后亏损；按单位敞口计不如两个基准。
- **ETH：** 日夏普不大于 1；成本翻倍后亏损。

### 解读

- **成交多、敞口低：** 策略平均敞口只有 0.1%–0.3%，每年却成交 300 多笔。研究里的仓位计算沿用生产的分档仓位规则，杠杆按 1 计。主要问题是信号太弱、换手太高，成本吃掉了微弱的信号。
- **基准门槛受敞口影响：** ETH 的“单位敞口收益跑赢基准”这一条之所以成立，是因为敞口极低，单位敞口收益被放大，不能当作优势证据。
- **基准本身也不好：** 这一年买入持有和趋势基准都大幅亏损（熊市年份）。

## 2026-11-13 独立审计补记（结果无效 + 最终测试再次查看）

- **最终测试窗口又被查看了一次。** 审计时用冻结模型与 `final_config` 重放了 2025-11-16 至 2026-11-12（数字与上表逐位一致），并查看了该窗口内的退出原因和持仓时长，缺陷正是由此确认的。修复后不得用这一窗口做任何选择或判定；修复后的重评只能到验证集为止，最终测试改用 2026-11-13 之后的前瞻纸面数据。
