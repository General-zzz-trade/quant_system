# BTC/ETH 多周期策略：研究、纸面与实盘路径（2026-11-13）

**结论：** 第一版多周期策略**未通过**预先声明的上线门槛，主网执行会被代码拒绝。研究引擎、运行时和纸面运行链路已经完成，并逐笔验证与研究一致，可以直接用于下一轮研究和前瞻纸面运行。

## 1. 架构（一个函数贯穿研究与实盘）

```
1h 收盘 K 线 ──┬─> 聚合出完整的 4h / 日线 K 线（日线在次日 00:00 UTC 后才可见）
              └─> lab.strategy.compute_targets / latest_target   ← 研究与实盘调用同一个函数
                     日线：多回看期趋势得分 × 目标波动率 ÷ 实际波动率（核心）
                     资金费：拥挤一侧仓位减半（可选层）
                     4h：波动突变降仓 / 24h 趋势确认（可选层）
              ─> lab.rebalance.plan：差额超过阈值才交易；缩仓用 reduce-only，加仓用入场单
              ─> 纸面：研究撮合模型 BarBroker │ 实盘：币安持久化执行 + 门禁 + 交易所端止损
```

- **截尾窗口一致：** 所有特征都是有限滚动窗口，实盘只用尾部窗口算出的值与用全量历史算出的完全一致（`tests/unit/lab/test_lab_engine.py`）。
- **纸面与研究一致：** 纸面运行时（`runner/binance_target.py`）在同一段 K 线上，与研究模拟（`lab/simulate.py`）的成交和权益逐笔一致，市价、挂单 1 小时、挂单 4 小时三种执行方式都已测试（`tests/unit/lab/test_target_runtime.py`）。
- **执行模式：** 复用币安持久化执行（超时不重发，查无此单 90 秒后结算）、交易所端止损、kill switch、峰值回撤平仓、3 倍总敞口上限；重启后从日志恢复，已测试。

## 2. 研究协议与结果（`research/results/lab_2026-11-13/`）

候选和门槛都在运行前写死在 `lab/study.py` 中，研究代码在运行前已提交（`6d27c6c`）。

- **数据：** 币安 BTC/ETH 永续 1h K 线与资金费。评估期 2021-01-10 至 2025-11-16。
- **次要留出期：** 2025-11-16 至 2026-11-12。这段走势在上一轮研究中已整体看过，只报告，不参与选择。
- **分段选择：**
  1. 日线层 12 个候选：3 组回看期 × 两种信号 × 是否只做多；
  2. 4h 和资金费层 8 种组合，加入后夏普至少提高 0.05 才采用；
  3. 执行方式 3 种。

  总共试验 39 个配置。
- **滚动前推：** 2022、2023、2024、2025 每年都只用此前的数据重新完整选一次，再测该年，用来诚实估计“选择流程”本身的样本外表现。

### 结果

| | 夏普（日） | 收益 | 最大回撤 |
|---|---:|---:|---:|
| 开发期，选中配置（样本内） | 0.75 | 年化 11.9% | 18.7% |
| 滚动前推样本外（2022–2025） | **0.18** | 累计 +6.5% | 32.1% |
| 滚动前推样本外，成本翻倍 | 0.07 | — | — |
| 次要留出期 | −0.42 | −4.5% | 7.4% |
| 同期买入持有（BTC/ETH 各半），开发期 | 0.66 | 累计 +184% | 76.3% |
| 同期买入持有，次要留出期 | −0.41 | −28.5% | 46.5% |

- **滚动前推各年：** 2022 年 −10.7%，2023 年 −9.2%，2024 年 +28.8%，2025 年 +2.0%。
- **选中的配置：** 回看期 10/30/90 天，信号取方向，只做多，不加任何附加层，市价执行。每个币种每年约 60 笔成交，平均敞口约 0.2 倍权益。
- **日线候选的表现：** 只做多的 6 个候选夏普在 0.57–0.75，可以做空的在 0.32–0.64，说明“只做多”是一个稳定的平台区，不是孤立的尖峰。
- **附加层没有帮助：** 4h 确认稳定拉低表现，在 0.38–0.43 之间；资金费过滤、波动突变降仓没有提升；挂单执行只多出 0.03，没达到 0.05 的采用标准。
- **扣除 39 次试验后：** 真实夏普大于 0 的概率为 0.71，低于门槛 0.9。

### 门槛逐项结果

| 检查项 | 结果 | 要求 | 是否通过 |
|---|---:|---:|---|
| 滚动前推夏普 | 0.18 | ≥ 0.8 | ✗ |
| 成本翻倍后夏普 | 0.07 | ≥ 0.4 | ✗ |
| 最大回撤 | 32% | ≤ 35% | ✓ |
| 扣除多次试验后概率 | 0.71 | ≥ 0.9 | ✗ |
| 每币种年成交笔数 | 67 | ≤ 150 | ✓ |
| 样本外为正的年份 | 2 | ≥ 3 | ✗ |

### 解读

- **它是“降回撤的持仓”，不是超额收益。** 只做多的日线趋势加波动率目标，夏普与买入持有相近，但回撤从 76% 降到约 19%–32%。
- **选择不稳定。** 滚动前推里每年选中的回看期在 10/30/90 天和 30/90/180 天之间来回切换，样本外表现明显低于样本内，这是典型的“选择带来的乐观偏差”。
- **不要据此修改参数后重跑同一段数据**，否则就是用结果挑参数。下一轮研究必须先登记新假设，最终测试用前瞻纸面运行。

## 3. 使用方法

```bash
# 研究（输出目录必须为空）
python3 -m lab.study --data-dir data_files/binance_public --out research/results/lab_<日期>

# 发布冻结的策略（签名）；门槛未通过时，主网执行仍会被拒绝
QUANT_MODEL_SIGN_KEY=... python3 -m scripts.publish_strategy_spec --study research/results/lab_<日期> --out models_binance/strategy

# 纸面运行（默认）：行情来自主网公开接口，撮合模型与研究相同
python3 -m runner.binance_target --spec models_binance/strategy/final_spec.json
# 服务器常驻运行：infra/systemd/binance-target.service（默认纸面模式）

# 测试网执行（需要测试网 API key，RISK_SCOPE 必须含 binance 和 testnet）
RISK_SCOPE=binance-testnet-main python3 -m runner.binance_target --spec ... --enable-execution
```

- **输出文件：**
  - `data/runtime/binance_target/target_status.json`：每 5 秒更新的状态；
  - `target_events.jsonl`：K 线、目标仓位、订单意图、纸面成交与权益、问题记录。
- **kill switch：** `python3 -m shared.kill_file activate --flatten --path data/runtime/binance_target/kill_switch.json`。
