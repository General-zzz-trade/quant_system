## 成本模型（每个测试都要含）

- 手续费：币安 VIP0，挂单 0.02%、吃单 0.05%。
- 资金费：按实际结算记录。
- 滑点：市价 3 个基点，止损 10 个基点。
- 敏感性：手续费翻倍再测一次。
- 已下架合约照样参与，下架后的仓位按最后价格平掉。

## 切分

- 2022-11-13 到 2026-05-12：用来挑选，按年滚动前推。
- 2026-05-13 到 2026-11-12：当晚不参与挑选，只用来回答"在没见过的数据上还赢吗"。
  - BTC/ETH 的这一段以前的研究看过，这一点要如实标出。

## 打分（1–5 分，每项）

扣成本后的滚动前推收益、最大回撤、交易笔数、最长连亏、熊市和震荡期的表现。

**扣成本后跑不赢买入持有的，不交易。**

## 加冕冠军前的最终检查（每张卡都要回答）

1. 在没见过的数据上还赢吗？
2. 扣了手续费和资金费还赢吗？
3. 至少 50 笔交易吗？
4. 手续费翻倍还成立吗？
5. 参数换成邻近值还成立吗，还是只靠一个幸运值？
6. 有没有数字从未来泄漏？用 `lab/causality.py` 的检查。

每张卡以 **WHY THIS COULD FAIL** 结尾。宁选平淡可靠的，不选刺激侥幸的。实验室的冠军一律标为"未验证"：同一批数据上挑出来的最好者，带着挑选偏差。

## 策略卡

- 一句话想法；为什么有优势、谁在付钱。
- 精确的入场、出场、止损规则；每笔的仓位。
- 扣成本后的结果对比买入持有；滚动前推结果。
- 最差的月份；最长连亏。
- 杀死它的市场条件；它开始失效的第一个迹象。

## 规则

- 只用有来源、有时间戳的真实数据。绝不编造价格、成交、回测数字或盈利；估计一律标"估计"。
- 每个测过的配置都登记到 `research/lab/trials.jsonl`：日期、想法、参数、窗口、结果。多重检验按整组扣减。
- API Key 只开交易、不开提现，绝不进代码或聊天；实验室不碰交易所账户。
- 先模拟盘，再真钱。模拟盘目前没部署（技术负责人 2026-11-16）；真钱要等技术负责人说"go live"，而且主网目前被代码拒绝。
- 卡住时留一个问题给技术负责人，然后继续。
