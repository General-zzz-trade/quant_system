## 成本模型（每个测试都要含）

- 手续费：币安 VIP0，挂单 0.02%、吃单 0.05%。
- 资金费：按实际结算记录。
- 滑点：市价 3 个基点，止损 10 个基点。
- 敏感性：手续费翻倍再测一次。
- 已下架合约照样参与，下架后的仓位按最后价格平掉。

## 实盘条件（技术负责人 2026-11-16：回测按实盘的方式算）

候选策略一律用 `run_idea(..., live=LIVE)` 回测（`lab/um_lab.py` 的 `LiveTerms`）：
- 资金 300 USDT（小资金实盘的 `STRATEGY_CAPITAL_USDT`），在策略的固定品种清单上平分，与实盘程序的 1/N 分配相同；
  低于交易所最小下单额的单不发。品种清单要固定：实盘程序只交易规格里列出的品种。
- 每个仓位有交易所 8% 止损（实盘程序的默认值）：K 线内触及就按止损价成交，跳空越过就按开盘价成交，再差 10 个基点，
  收吃单手续费。
- 止损后该品种暂停入场 4 小时，到时自动解除（技术负责人 2026-11-16 选择自动解除、4 小时）。实盘程序一侧按资金路径
  完整流程改，改好前实盘仍要人工解除。
- 收益按整份资金算：没在交易的份额算现金。
- 报告里要写：
  - 实盘下单限额要放到多大：每天最多几笔入场、每天名义额、单笔最大、一小时最多几笔（技术负责人按这个改实盘配置）；
  - 试运行硬止损会触发几次：90 天的试运行里有多大比例会亏到 15% 被叫停（`loss_stop_share`）、日亏 3% 的天数（按日收盘算，盘中触发会更多）。旧口径"连亏 3 笔"仍然列出，只作参考。
- 还没模拟的实盘差别：
  - 回撤锁定和 3 倍敞口按整个账户算（技术负责人的选择；账户大时很少触发）；
  - 每品种按自己的盈亏复利，实盘是共用一份资金（差别是二阶的）；
  - 小币种的买卖价差按统一的 3 个基点估计。

## 打分（1–5 分，每项）

扣成本后的滚动前推收益、最大回撤、交易笔数、最长连亏、熊市和震荡期的表现。

**扣成本后跑不赢买入持有的，不交易。**

## 加冕冠军前的最终检查（每张卡都要回答）

1. 在没见过的数据上还赢吗？
2. 扣了手续费和资金费还赢吗？
3. 至少 50 笔交易吗？
4. 手续费翻倍还成立吗？
5. 参数换成邻近值还成立吗，还是只靠一个幸运值？
6. 有没有数字从未来泄漏？用 `lab/causality.py` 的检查。
7. 按实盘条件（300 USDT、8% 止损、止损后暂停）还成立吗？需要多大的下单限额？试运行硬止损多久触发一次？

每张卡以 **WHY THIS COULD FAIL** 结尾。宁选平淡可靠的，不选刺激侥幸的。实验室的冠军一律标为"未验证"：同一批数据上挑出来的最好者，带着挑选偏差。

## 策略卡

- 一句话想法；为什么有优势、谁在付钱。
- 精确的入场、出场、止损规则；每笔的仓位。
- 扣成本后的结果对比买入持有；滚动前推结果。
- 最差的月份；最长连亏。
- 实盘条件下的结果、需要的下单限额、硬止损触发次数。
- 杀死它的市场条件；它开始失效的第一个迹象。

## 规则

- 只用有来源、有时间戳的真实数据。绝不编造价格、成交、回测数字或盈利；估计一律标"估计"。
- 每个测过的配置都登记到 `research/lab/trials.jsonl`：日期、想法、参数、窗口、结果。多重检验按整组扣减。
- API Key 只开交易、不开提现，绝不进代码或聊天；实验室不碰交易所账户。
- 过线的想法先冻结规则，在新数据上跟踪 4 周：每周登记一次查看（`research/forward_looks.jsonl`，照前向检验协议的做法），每次用新下载的快照重跑；四次都成立才进小资金实盘试运行（技术负责人 2026-11-16 晚）。这不是模拟盘，不部署任何东西。
- 不做模拟盘和测试网（技术负责人 2026-11-16）。上小资金实盘之前要满足：技术负责人亲自把签名规格标为"已通过"（代码从不改它）、账户里没有程序账本以外的仓位、Telegram 和心跳配好、主机装好、有策略资金上限；真钱要等技术负责人说"go live"。
- 卡住时留一个问题给技术负责人，然后继续。
